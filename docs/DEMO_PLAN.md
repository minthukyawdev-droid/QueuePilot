# QueuePilot Demo Plan

This is a planned future demo. None of the described product behavior is implemented in the foundation.

## Reliability

- Use controlled or mock queue data during the demo.
- Use fictional personal data.
- Rehearse the exact sequence after deployment.
- Prepare screenshots or a recorded fallback for external integration failures.
- Do not rely on an uncontrolled live government system.

## Story

Show the waiting problem, demonstrate how preparation creates value during the wait, and finish with a clear approaching-turn alert. Keep the narration centered on user value rather than implementation details.
